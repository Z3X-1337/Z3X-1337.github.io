Evidence handling / field note 03

IOC provenance is part of the finding.

An extracted indicator is more useful when the raw match, normalized value, source context, and analyst caveats remain connected.

Zaid Hijazi13 Aug 202604 min read

On this page

Indicators of compromise are commonly moved from logs and notes into tickets, reports, scripts, and blocklists. In that journey it is easy to preserve only the cleaned value and lose the details that make it reviewable.

The normalized value is useful for matching. The original form and source context are useful for understanding what was actually observed. Strong evidence handling keeps both.

Normalization changes evidence

Defanging and refanging are common examples. A note may contain an intentionally altered URL to reduce accidental clicks. A tool can normalize it for structured output, but that transform should not erase the original representation or imply that the value has been independently verified.

raw_match:        hxxps://example[.]test/login?source=report
normalized_value: https://example.test/login?source=report
indicator_type: url
source_context: analyst-note.txt:14
transform:        refanged
validation:       syntax only; no enrichment performed

That small record says much more than a standalone URL. It tells a reviewer why the strings differ, where the match came from, and where the process stopped.

What to retain

The right data model will vary by workflow, but a compact, reviewable record usually includes the following:

  • the raw match as it appeared in the input;
  • a normalized value when a safe, documented transformation applies;
  • the indicator category and validation outcome;
  • the source location or surrounding context available to the tool; and
  • any limitations, such as an absent enrichment step or unsupported input form.

Safe sharing is deliberate

Defanged representations can make reports safer to copy and discuss, but they are not a security guarantee. Output design should make the state clear, especially when people could paste a value into another tool. A clear label is more useful than silently changing a value and hoping the next reader notices.

Evidence principle

Preserve the original matched form, the normalized value, and the transformation between them. A finding remains easier to validate when its provenance stays attached.

Keep the limits visible

IOC Sanitizer focuses on extracting, validating, normalizing, defanging, and refanging supported common indicators. It is a local utility; it does not claim that an indicator is malicious, active, or relevant to a particular incident.

That boundary is not a weakness. It is what lets the output remain deterministic and honest enough for someone else to inspect, reproduce, and build on.
